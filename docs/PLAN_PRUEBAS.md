| **T09** | Donante consulta donación ajena                     | 403/404 sin filtración                                         | `GET /v1/donations/{id}` utilizando el token de donante2 sobre un recurso ajeno.        | `evidence/T09-anti-bola.png`                   |
| **T10** | Lambda de listado intenta escribir en DynamoDB      | `AccessDenied` y error controlado                              | Inspección de la política IAM mínima generada en SAM.                                   | `evidence/T10-iam-minimo.png`                  |
| **T11** | Usa un ID token o un token alterado                 | ID token: 403 (firma válida, sin scopes); token alterado: 401. | `GET /v1/donations/me` primero con un ID token y luego con un access token alterado.    | `evidence/T11-jwt-alterado.png`                |
| **T12** | Gestor consulta historial de un donante             | 403/404                                                        | `GET /v1/donations/me` utilizando un token con rol GESTOR.                              | `evidence/T12-gestor-donaciones-403.png`       |

| **T14** | Usuario GESTOR inicia sesión sin segundo factor     | No obtiene tokens                                              | Intento de autenticación Cognito con usuario GESTOR omitiendo el reto TOTP MFA.         | `evidence/T14-mfa-gestor.png`                  |
