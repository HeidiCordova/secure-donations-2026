# Evidencias

Las evidencias se nombran con el ID de prueba y una descripción breve en minúsculas, por ejemplo `T09-donacion-ajena-404.jpg`. No se usan extensiones dobles ni comas en los nombres. Cada prueba tiene una sola captura principal; los resultados complementarios pueden documentarse en Markdown.

Antes de subir una captura, ocultar por completo tokens, `sub`/`donorSub`, contraseñas, códigos MFA, correos, teléfonos, direcciones e IDs de cuenta. Verificar que las variables de la solicitud estén resueltas y que la respuesta capturada corresponda al resultado esperado; una respuesta de autenticación causada por una variable vacía no demuestra una prueba de autorización.
