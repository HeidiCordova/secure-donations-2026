# Infraestructura (Heidi)

`template.yaml` de AWS SAM con el stage `academic`: Cognito, HTTP API con JWT authorizer, Lambdas con un rol IAM por función, DynamoDB, S3 + CloudFront con OAC y response headers policy, log groups con retención de 14 días.

Se despliega desde AWS CloudShell (región `us-east-2`).
